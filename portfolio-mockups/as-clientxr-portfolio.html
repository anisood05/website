// The Problem

Aukett Swanke needed to share immersive 360° project walkthroughs, fly-through videos and drawing packs with clients before handover — without exposing a public CMS, and while satisfying PI-insurance requirements for a verifiable second access factor.

// My Contribution

Designed and built the full system solo: the client-facing landing/viewer, the admin dashboard for project and content management, the Supabase schema and RLS policies, the SHA-256 password + access-code auth flow, and the Cloudflare Pages deployment — zero build step throughout.
